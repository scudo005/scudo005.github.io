I wanted to figure out if the computer players are actually cheating/rubberbanding to have close matches, so I started decompiling the game.
Since doing this sucks, I am going to write down what I find out so nobody has to do this shit again.

In order to make Ghidra capable of dealing with .dol executables, you need the appropriate extension (this one).

Importing symbols

The game uses Nintendo's relocatable sections format, and on all versions it also ships two symbol maps: one is called main.sel, which uses the SEL file format (of which I'm not sure if it was made by Nintendo or by Metrowerks, since they provided the PowerPC compiler toolset to Nintendo), and the second is called homebutton.rso, which contains a bunch of other maybe unused symbols and is maybe in a different format, but I haven't checked that file yet.

There is a Python 2 script to extract the data out of the proprietary SEL file; to run it, you have to spin up a Python 2.7 Docker container and run it from there:

docker run --rm -it -v "$(pwd):/work" python:2.7-slim bash
python /work/sel_parser.py main.sel > sym.txt

As you can see, this outputs physical addresses with their section. This is not very useful, so I slopped up a script to convert it to Ghidra's own format and automatically import all symbols. (Reminder to start Ghidra in Python mode.) Some symbols are skipped because they reference inexistent memory addresses, and some symbol names are truncated to deal with Ghidra's 2000 character limit for symbol names. (yes, this is a thing, apparently.). (Also, the script may output text directly, I redirected stdout and I haven't checked if it can write directly to a file and in which format it does write to a file.)

Demangling symbols

Now that you have most of your symbols imported, they will be mangled (because you may have overloaded functions and this will distinguish every unique symbol in your code); to do this, you may install this extension.

This is a fork of another extension (that hasn't been updated in 5 years) so it can work with the current latest version of Ghidra (12.1), but you need it to compile it yourself. Luckily there is a conveniently provided build.sh.

Not all symbols will be demangled, especially really long ones, but most of the work should have been done by this point.

Of course, given my amazing luck with computers, the extension didn't work correctly, so I slopped up another script to demangle symbols for me.
